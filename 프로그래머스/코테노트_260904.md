## 1️⃣ 문제의 큰 유형 — "이건 무슨 문제인가"

문제를 보면 먼저 **두 갈래**로 갈라서 생각하기:

```
                문제
          ┌──────┴──────┐
     최적화(시복도)      풀이 방법
          │               │
     완전탐색이 답?   →  정렬 / 자료구조로 최적화
     (N이 작을 때)       (스택, 투 포인터, 이분탐색 …)
```

- **완전탐색**으로 답이 나오는지 먼저 판단 → N 범위를 보고 결정
- 시간 초과면 **정렬·자료구조로 최적화**하는 방향으로 전환

---

## 2️⃣ 극단적인 경우의 시간복잡도 — "N이 최대일 때 버티나"

코딩 전에 **최악의 입력**을 넣어보고 복잡도를 먼저 계산한다.

### P0. 두 개 뽑아서 더하기
- 두 수를 뽑는 경우의 수 = N(N-1)/2 ≈ **O(N²)** 쌍
- `set` 에 넣으면 삽입마다 O(log N) → 전체 **O(N² log N)**, 대신 **자동 정렬 + 중복 제거**
- ※ 대안: `vector` 에 다 담고 `sort` + `unique`
  - 복잡도 급은 비슷하지만 **상수가 작아 보통 조금 더 빠름** → 내 필기의 "vector + sort + unique가 더 빠름" 이 맞음

### P1. 나머지가 1이 되는 수 찾기
- 그냥 1씩 늘리며 찾기(완전탐색) → **O(N)**
- 약수의 성질을 이용하면 → **O(√N)** ✅
  - ※ √N 까지만 확인하면 되는 이유: 약수는 √N 을 기준으로 **쌍**으로 나타나기 때문

> 💡 **정리**: "극단적인 경우"를 떠올리는 습관 = 완전탐색 O(N)/O(N²) 을 O(√N)/O(N log N) 으로 낮출 수 있는지 항상 자문하기.

## 3️⃣ 새로 배운 문법 정리 (C++)

### `set` — 중복 제거 + 자동 정렬
```cpp
set<int> s;         // 삽입/탐색 O(log N), 항상 오름차순 정렬 상태 유지
s.insert(x);
if (s.count(x)) ... // 존재 판별
```

### `vector` + `sort` + `unique` — 중복 제거 (더 빠른 경우)
```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
// ※ unique 는 중복을 "뒤로 몰기"만 하므로 erase 와 반드시 세트로!
```

### `.size()` 로 원소 개수 측정
```cpp
numbers.size();     // 반환형은 unsigned → 뺄셈 시 언더플로 주의
```

### `while (n > 0)` 로 자릿수 분리 (P2)
```cpp
int sum = 0;
while (n > 0) {     // n 이 0이 될 때까지
    sum += n % 10;  // 마지막 자리
    n /= 10;        // 자리 내리기
}
// ※ 아스키(문자열) 방식: '3' - '0' == 3 로도 자릿수 추출 가능
```

## 4️⃣ 외워야 하는 공식 ⭐

### 동전 최소 개수 DP (P3)
```cpp
// dp[j] = 금액 j 를 만드는 최소 동전 개수
vector<int> dp(target + 1, INF);   // 목표 금액 크기로, 큰 값으로 초기화
dp[0] = 0;                         // 0원은 0개

for (int i = 0; i < n; i++) {      // 동전 종류마다
    int coin = arr[i];
    for (int j = coin; j <= target; j++) {   // 2중 포문
        dp[j] = min(dp[j], dp[j - coin] + 1);   // ⭐ 핵심 점화식
    }
}
```

**점화식 읽는 법**: `dp[j]` = "지금까지 방법" vs "이 동전을 한 개 더 쓴 `dp[j-coin] + 1`" 중 **더 적은 쪽**.

> 🔑 이 형태(`dp[j] = min/max(dp[j], dp[j-x] + ...)`)는 **배낭·거스름돈·조합** 문제에서 계속 재등장한다. 통째로 외워두기.
